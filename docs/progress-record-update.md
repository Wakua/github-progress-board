# 証拠付き進捗記録の更新

## 固定案

server/progress-update.mjsの記録時点と証拠に基づく、既存作業向けの固定案を扱う。対象は同梱のサンプル記録（架空）にある、レシピアプリの利用条件の確認と献立の自動作成、本人限定の公開、予約管理アプリの利用者による評価である。技術完了と人間受入を区別し、予約管理アプリには時点付きの証拠だけを追記する。

現在の進捗への適用前に、後続PRと人間判断を再確認する。この統合・検証では本番へ適用しない。

## 保存条件

previewで原本と現在の作業を照合し、見積以外が編集された作業を除外する。除外された未完了の前提を持つ後続作業も、完了させない。

確認した固定案だけを[本人限定MCPの保存契約](sites-mcp.md#契約と保存)で適用する。任意の状態変更を受け付けず、見積、条件本文、原本の証拠、既存履歴、他作業を保持する。追加履歴は記録を更新した日時であり、過去の実作業日時として扱わない。
