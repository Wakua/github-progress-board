## 管理元

| 情報 | 管理元 |
| --- | --- |
| 到達目標と段階の順序 | 親Issue |
| 完了条件・前提・判断結果・検証の根拠 | 対応する子Issue |
| 進行状態と担当・Iteration・Estimate | GitHub Project |
| 採用済みの動作 | 仕様と運用 |

観察資料と画面記録はGit管理外の `references/` に保存する。公開ソースへ試作の報告、実際の報告者情報、添付本体を含めない。
